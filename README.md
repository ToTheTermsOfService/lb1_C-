Якщо число рядків в двовимірному прямокутному масиві дорівнює nRows, а число стовпців nColumns, то одновимірний масив повинен мати nRows * nColumns елементів, в двовимірних зубчастих масивах загальне
число елементів також повинно дорівнювати nRows * nColumns. Значення nRows та nColumns вводяться в процесі роботи додатку у вигляді одного рядка з розділювачем. В запрошенні вводу для користувача повинна
бути присутня інформація про те, які символи є розділювачами (число розділювачів повинно бути більшим ніж 1). За допомогою методу Split класу System.String додаток обробляє введену користувачем 
інформацію про число рядків та стовпів та присвоює значення відповідним змінним, які відповідають за nRows та nColumns. В першій лабораторній роботі не обов'язково обробляти помилки введення даних,
припускається, що користувач вводить правильні дані. Додаток розподіляє пам'ять для всіх масивів та ініціалізує елементи масивів. Для ініціалізації елементів можна використати конструктор без параметрів.
